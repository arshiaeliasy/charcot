## ✨ امکانات

- 📚 **۹ بخش آموزشی**: علوم پایه (۱۹ درس)، فیزیوپاتولوژی، استاجری، پره‌انترنی، اینترنی، کیس‌های بالینی، یادداشت‌های بالینی و...
- 🔎 **جستجوی سریع** با `Ctrl + K` روی همهٔ صفحات (با لینک مستقیم به هر موضوع)
- 🌙 **تم روز/شب** با ذخیره در حافظهٔ مرورگر (بدون پرش هنگام بارگذاری)
- 📱 **ریسپانسیو کامل** با منوی موبایل بهینه
- 🗂️ **آکاردئون‌های قابل لینک** — هر موضوع آدرس یکتای `#hash` دارد
- 🔔 **Toast** به‌جای `alert()` برای پیام‌ها
- ⬆️ **دکمه بازگشت به بالا** و نوار پیشرفت اسکرول
- ⚡ **ساختار سبک استاتیک** — بدون فریم‌ورک، بدون مرحلهٔ بیلد

## 🗂️ ساختار پروژه

```
charcot/
├── index.html              صفحهٔ اصلی (لندینگ + ورود/ثبت‌نام)
├── basic-sciences.html     علوم پایه (۱۹ درس آکاردئونی)
├── pathophysiology.html    فیزیوپاتولوژی
├── externship.html         استاجری
├── pre-internship.html     پره‌انترنی
├── internship.html         اینترنی
├── clinical-cases.html     کیس‌های بالینی تشریحی
├── clinical-notes.html     یادداشت‌های کانال (۳۰ موضوع)
├── case-stroke.html        کیس سکتهٔ مغزی
├── case-acs.html           کیس سندرم حاد کرونری
├── case-sepsis.html        کیس سپسیس
├── about-us.html           درباره ما
├── css/style.css           استایل مشترک همهٔ صفحات
├── js/main.js              جستجو، تم، منو، آکاردئون، Toast
├── fonts/                  فونت وزیرمتن (خودمیزبان، ۴۰۰/۷۰۰/۸۰۰)
├── supabase/schema.sql     اسکیمای دیتابیس کاربران
├── robots.txt / sitemap.xml
└── DATABASE.md             راهنمای ۵ قدمی راه‌اندازی Supabase
```

## 🚀 اجرا به‌صورت محلی

```bash
python -m http.server 8123
# سپس http://localhost:8123 را باز کنید
```

## 🌐 انتشار رایگان روی GitHub Pages

1. این مخزن را با `git push` به‌روز کنید
2. در تنظیمات مخزن → **Pages** → Source: `Deploy from a branch` → شاخه `main`
3. سایت چند دقیقه بعد روی `https://<username>.github.io/charcot/` فعال می‌شود

## 🗄️ دیتابیس (اختیاری)

برای فعال‌سازی ثبت‌نام کاربران، مراحل ۵ گانهٔ [DATABASE.md](DATABASE.md) را دنبال کنید.
